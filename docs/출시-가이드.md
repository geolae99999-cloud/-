# VocaPro 플레이 스토어 출시 가이드

앱은 웹사이트(https://vocapro.kro.kr)를 주소창 없이 여는 안드로이드 앱(TWA)이에요. 사이트를 고치면 앱도 바로 바뀌어서, 기능을 고칠 때마다 스토어에 다시 올릴 필요는 없어요. 스토어에는 앱 껍데기(`android/`)만 올려요.

## 1. 서버 준비 (한 번만)

Supabase 대시보드 > SQL Editor에서 아직 안 돌린 파일을 순서대로 실행해요.

- `supabase/sql/supabase_update_v21.sql`: 친구 초대 보상. 실행 전에는 앱이 초대 보상을 약속하지 않고 그냥 링크만 공유해요.

## 2. 앱 파일(AAB) 만들기 (내 컴퓨터, Android Studio)

1. Android Studio에서 `android` 폴더를 열어요.
2. Gradle 업데이트를 물으면 '업데이트'를 눌러요. API 36으로 빌드하려면 Android Gradle Plugin 8.10 이상, Gradle 8.11.1 이상이 필요해요(`android/build.gradle`에 8.10.1로 맞춰 둠).
3. 서명 키 정보는 저장소 밖 `C:/Users/<나>/Android/vocapro-signing/keystore.properties`에서 읽어요. 이 파일과 키 파일은 절대 저장소에 올리지 말고, 잃어버리지 않게 따로 백업해요.
4. Build > Generate Signed App Bundle > Android App Bundle > release로 만들어요. 결과: `android/app/release/app-release.aab`
5. 업데이트를 올릴 때마다 `android/app/build.gradle`의 `versionCode`를 1씩 올려요(지금 2, `versionName` 1.1.0).

구글 플레이 규칙: 2026년 8월 31일부터 새 앱과 업데이트는 Android 16(API 36) 이상을 대상으로 해야 해요. `targetSdk 36`으로 맞춰 뒀어요.

## 3. 앱과 사이트 연결 확인 (중요)

앱이 주소창 없이 열리려면, 사이트의 `public/.well-known/assetlinks.json`에 **구글이 앱에 서명하는 키**의 지문이 있어야 해요. 없으면 앱 위에 주소창이 보여요.

1. Play Console > 앱 > 테스트 및 출시 > 설정 > 앱 무결성 > 앱 서명에서 'SHA-256 인증서 지문'을 복사해요.
2. `public/.well-known/assetlinks.json`의 `sha256_cert_fingerprints` 배열에 그 값을 **추가**해요(지금 있는 업로드 키 지문은 그대로 둬요).
3. 푸시하고, https://vocapro.kro.kr/.well-known/assetlinks.json 이 열리는지 확인해요.

## 4. Play Console 등록 순서

1. 개발자 계정 만들기(등록비 25달러, 본인 인증).
2. 앱 만들기: 이름 VocaPro, 기본 언어 한국어, 앱, 무료.
3. **개인 개발자 계정이면** 바로 정식 출시가 안 돼요. 비공개 테스트에 테스터 12명 이상이 14일 동안 참여해야 정식 출시를 신청할 수 있어요. 반 학생이나 친구에게 부탁하면 좋아요.
4. 아래 5~7을 채우고, 비공개 테스트 → (14일 뒤) 프로덕션 순서로 AAB를 올려요.

## 6. 앱 콘텐츠(정책) 답변 가이드

- **광고**: 광고 없음.
- **앱 액세스 권한**: 로그인해야 쓸 수 있어요 → 심사용 테스트 아이디와 비밀번호를 적어 줘요(서버 계정으로 하나 만들어 두기).
- **콘텐츠 등급**: 설문에서 교육, 폭력·성적 내용 없음, 사용자끼리 대화 없음(랭킹 이름은 보임)으로 답해요.
- **타겟층**: 초등학생도 쓰면 '13세 미만 포함'을 고르게 되고, 이때 구글 '가족 정책'을 따라야 해요. VocaPro는 광고가 없고 만 14세 미만은 이 기기에만 저장하는 계정으로 만들어서 잘 맞지만, 심사가 더 꼼꼼해요. 처음엔 '13세 이상'으로 내고 나중에 넓히는 방법도 있어요.
- **데이터 보안** (개인정보처리방침과 같게):
  - 수집: 이메일 주소, 이름(또는 별명), 사용자 ID, 앱 활동(학습 기록·단어장), 음성(발음 평가 과제를 낼 때만, 선택)
  - 목적: 앱 기능, 계정 관리
  - 공유: 제3자와 공유 안 함(반에 참여한 경우 그 반 선생님에게만 이름·학번·학습 요약)
  - 전송 중 암호화: 예(HTTPS)
  - 삭제 요청: 예. 앱 안 설정 > '계정과 데이터 삭제'
- **계정 삭제 URL** (구글이 요구): https://vocapro.kro.kr 에서 로그인 → 설정 → '계정과 데이터 삭제'라고 적어요.
