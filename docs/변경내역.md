## 고친 오류
- 단어장 화면에서 번역 버튼과 단어 추가(+) 버튼이 겹치던 문제
- 홈 화면 바로 학습 타일의 깨진 HTML 속성(`class="..."" `)
- 듣기 모드의 이모지 기호(⏮⏸▶)를 선 아이콘으로 교체
- 짝 맞추기 섞기가 한쪽으로 치우치던 문제
- 쓰지 않는 Fraunces 글꼴과 중복된 Pretendard 로딩 제거 (첫 화면 속도)
- 동작하지 않던 비밀번호 재설정 코드 제거
