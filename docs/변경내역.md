# 단어 추가, 읽어주기, 번역기, 디자인 (2026-10-13)

- 읽어주기: 뜻(한국어)을 읽을 때 단어를 읽은 목소리와 같은 회사·같은 성별 목소리를 골라요. 여러 언어를 읽는 목소리(Microsoft …Multilingual)면 뜻도 같은 목소리로 읽어요.
- 설정 > 읽어주기 · 목소리: 단어·예문 속도와 한국어 뜻 속도(0.5~2.0배, 0.05씩), 목소리 높이, 듣기 모드 쉬는 시간(0~5초), 단어 반복(1~3번), 언어별 목소리 고르기, 미리 듣기, 기본값으로.
- 듣기 모드 화면에서 바로 속도 바꾸기(−/+ 와 0.6~1.5배 버튼), 예문 해석도 읽기.
- 영어사전에서 한글 뜻으로 찾기 (예: 사과 → apple, apology). 중국어사전의 한글 뜻 찾기도 정확한 뜻이 먼저 나오게 고침.
- 번역기: Google 번역을 먼저 쓰고(안 되면 AI, 그다음 MyMemory), 한 단어면 품사별 다른 뜻과 내장 사전 뜻·예문도 보여줘요. 한→영에서 다른 후보 단어를 누르면 그 단어로 바꿔요.
- 오늘의 학습 아이콘이 깨져 "undefined"가 보이던 문제 고침.
- 영어 단어장 4개 추가: 필수 숙어·구동사 500, 생활·여행 영어 500, 토익 필수 600, 토플·텝스 고급 600.
